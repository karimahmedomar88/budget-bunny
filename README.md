# 🐰 Budget Bunny

**Making every pound count, one goal at a time.**

Budget Bunny is a simple financial planning app built with Python and Streamlit. It helps users organize their monthly expenses, track their remaining balance, and plan their savings goals.

## ✨ Features

### 💰 Monthly Budget Planner
- Enter your monthly income.
- Organize expenses into different categories.
- Calculate total expenses automatically.
- View your remaining balance.
- Get feedback based on your spending.

### 🎯 Savings Goal Calculator
- Set a personal savings goal.
- Enter how much you can save each month.
- Calculate how many months you need to reach your goal.
- See the total amount you will save.

## 🛠️ Built With
- Python
- Streamlit

## 🚀 Run the Project

1. Clone this repository:
   ```bash
   git clone https://github.com/karimahmedomar88/budget-bunny
   ```
2. Open the project folder:
   ```bash
   cd Budget-Bunny
   ```
3. Install Streamlit:
   ```bash
   pip install streamlit
   ```
4. Run the application:
   ```bash
   streamlit run app.py
   ```
